# 首轮 5 篇访问验证与初步分析

## 一、访问结论

本轮 5 个 `mp.weixin.qq.com/s/` 链接全部成功打开，均发现正文容器且正文从开头持续到文章结尾，没有出现登录墙、验证码、访问频率限制、删除提示或违规不可见提示。

成功率为 5/5（100%）。该结果只说明本轮浏览器环境和本轮时间点可访问，不能保证全部 138 篇都具有相同可访问性。

## 二、字段可得性

| 字段 | 结果 |
| --- | --- |
| 标题 | 5/5 可得 |
| 公众号 | 5/5 可得，其中第 4 篇需从页面分享元数据识别 |
| 独立作者 | 4/5 可得；第 4 篇未公开，不将 IP 属地误作作者 |
| 发布日期 | 5/5 可得；第 4 篇界面只显示月日，页面时间戳可还原年份 |
| 正文纯文本 | 5/5 可得 |
| 正文 HTML/排版结构 | 5/5 可得 |
| 正文图片节点 | 5/5 可统计；第 4 篇为 0 |
| 阅读、点赞、转发、收藏、评论数字 | 0/5 可得 |

“喜欢作者”是按钮文案，不是点赞量。本轮没有把不可见的互动数字推测为 0，也没有从标题中的热度表述反推流量。

## 三、样本的初步内容特征

仅作为首轮观察，不作为 138 篇总体结论：

1. 标题普遍使用具体冲突或反差：服务器崩溃、九旬院长与年轻妻子、绝密航天器、色情误判、新车起火。
2. 五个标题都含有高识别度实体或刺激词，并通过数字、疑问、感叹或事件结果增强点击动机。
3. 正文长度差异明显，纯文本约 529 至 2128 字；图片节点从 0 至 23 个，说明“高阅读样本”不能只用单一图文模板解释。
4. 汽车样本采用“突发事件/价格—事实展开—风险或竞争判断”的结构；艺术、航天和个人叙事样本分别依赖人物关系、稀缺信息和身份反差。
5. 第 4 篇证明微信公众号存在不同页面模板，批量流程必须允许多种元数据来源，并保留“未公开”状态。

## 四、对 138 篇去重样本的建议

建议继续批量处理，但采用“小批次、可恢复、保留证据”的方式：

1. 先按标准化 URL 去重：移除查询追踪参数，保留 `/s/<文章标识>`；再用公众号、标题、正文指纹做内容级去重。
2. 每批 10 至 15 篇，复用同一 Ego 任务空间，设置正常页面等待并在批次间控制访问节奏。
3. 原始层保存页面事实；规范层保存清洗字段；分析层只引用规范层，不覆盖原始证据。
4. 对异常页自动进入复核队列，不反复刷新：安全验证、频控、删除、违规、仅客户端可见、空正文、部分正文、模板未知分别记录。
5. 在抓取完成后再做选题、标题、内容结构、排版、情绪和流量机制分析，避免用 5 篇样本提前定型。
6. “高阅读量”必须有独立的阅读量来源或用户提供的榜单依据；微信桌面网页当前未提供这些数字，因此本轮只能研究被选入样本的文章特征，不能验证其实际阅读量。

## 五、下一阶段交付建议

- `articles.raw.jsonl`：每篇原始抓取记录。
- `articles.normalized.csv` 或 `.jsonl`：统一字段后的样本库。
- `crawl-log.csv`：每次尝试的时间、状态、失败原因、重试次数。
- `analysis/`：选题、标题、正文结构、排版、情绪、流量机制六个专题报告。
- `dedup-report.md`：URL 去重、内容去重及保留/剔除原因。

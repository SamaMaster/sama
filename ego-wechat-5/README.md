# 微信公众号高阅读量文章研究

本目录保存 138 篇去重微信公众号文章的浏览器实测结果、规范数据、统计分析与增长方案。采集时间为 2026-11-16（Asia/Shanghai），浏览器为用户指定的 Ego Lite。

## 文件说明

- `raw-results.json`：本地浏览器原始提取结果，包含首批正文纯文本、正文 HTML、元数据、可见互动区域和异常信息。
- `raw-corpus.jsonl`：本地 138 篇唯一链接的完整原始语料，每行一篇，包含正文、HTML、页面元数据和排版指标。
- `articles-normalized.csv`：规范化分析数据集，适合 Excel、Python、R 或 BI 工具继续分析。
- `corpus-metrics.json`：可复算的总体统计结果。
- `source-links.txt`：去重后的 138 个来源链接。
- `access-status.csv`：逐篇抓取状态与字段可得性记录。
- `full-analysis-report.md`：138 篇文章的选题、标题、内容、排版、情绪、擦边和流量机制详细报告。
- `growth-plan.md`：可执行的 30 天增长验证方案。
- `analysis-report.md`：首轮 5 篇访问结论和早期建议，作为过程证据保留。
- `methodology.md`：研究口径、采集流程、失败分类、质量控制和后续分析框架。
- `build-analysis.mjs`：从原始语料生成规范数据和统计指标的可复算脚本。
- `article-4-diagnostic.json`：第 4 篇特殊页面结构的复核证据。
- `round-01.mjs`、`round-02.mjs`：Ego Lite 浏览器验证脚本。

## 首轮结论

139 条原始链接包含 1 条完全重复，得到 138 条唯一链接。132 篇可访问，访问率 95.7%；6 篇失败中，3 篇触发微信安全验证，3 篇受作者隐私设置限制。桌面网页未公开阅读数、点赞数、转发数、收藏数或评论数，因此互动数字统一记为“不可得”，不得以按钮文案或外部传言替代。

## 版权与仓库策略

完整正文与 HTML 仅作为本地研究证据保留，已通过仓库根目录 `.gitignore` 排除，不提交到公开 GitHub 仓库。仓库提交来源链接、规范化特征、聚合统计、研究方法、报告和生成脚本，避免公开再发布第三方文章全文。

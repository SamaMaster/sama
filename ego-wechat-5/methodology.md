# 微信公众号文章样本研究方法

## 1. 研究目标

研究高阅读量微信公众号文章的选题、标题、内容、排版、情绪、流量机制与可复制方法。访问验证和内容分析分开进行：先确认页面事实，再进行解释，不用分析假设补齐缺失数据。

## 2. 数据分层

### 原始层

保存请求 URL、最终 URL、采集时间、导航异常、页面警告、正文文本、正文 HTML、图片节点数、页面公开元数据和可见互动区域。原始层不人工润色。

### 规范层

统一以下字段：

- `sample_id`
- `url`、`canonical_url`
- `crawl_status`、`failure_reason`
- `title`
- `author`
- `account`
- `published_at`、`modified_at`
- `ip_location`
- `body_text`、`body_html`
- `body_text_chars`、`image_nodes`
- `read_count`、`like_count`、`share_count`、`favorite_count`、`comment_count`
- `source_evidence`

缺失值使用 `null` 或“未公开”，不使用 0；只有页面明确显示数值 0 时才记录 0。

### 分析层

对规范层数据编码：

- 选题：领域、事件类型、时效、人物/品牌、稀缺性、争议性。
- 标题：长度、数字、实体、冲突、悬念、疑问、感叹、结果前置、情绪词。
- 内容：开头钩子、信息密度、段落结构、证据类型、叙事视角、结尾动作。
- 排版：段落长度、分节标题、图片密度、强调方式、留白、引导关注。
- 情绪：主情绪、强度、情绪转折、身份认同、风险/收益框架。
- 流量机制：搜索实体、社交谈资、争议驱动、热点时效、转发理由、账号受众匹配。
- 可复制性：可复用结构、适用领域、依赖资源、风险边界、验证指标。

## 3. 成功与失败判定

### 成功

同时满足：标题可识别、正文容器存在、正文非空、正文可从开头读取至可判断的结尾、无删除或访问限制提示。

### 部分成功

正文可读但关键部分缺失，或页面结构只允许提取部分字段。必须明确缺失字段，不得把摘要当全文。

### 失败原因枚举

- `security_verification`
- `rate_limited`
- `deleted_by_publisher`
- `policy_blocked`
- `wechat_client_only`
- `login_required`
- `empty_or_partial_body`
- `navigation_error`
- `unknown_template`
- `other`（附原始提示）

## 4. 完整性检查

1. 比较正文容器长度与页面可见正文。
2. 检查正文开头和末尾，不只读取首屏。
3. 记录图片节点和正文 HTML，以便后续研究排版；图片节点数不等于图片成功加载数。
4. 将页面按钮、推荐内容、关注提示与正文区分开。
5. 对异常模板单独复核元数据来源，禁止使用位置相近但语义错误的字段。

## 5. 去重方法

按三层执行：

1. URL 级：标准化主机、路径和追踪参数。
2. 元数据级：公众号 + 规范化标题 + 发布日期。
3. 内容级：正文去空白、去固定关注尾注后生成指纹；高相似记录进入人工复核，不自动删除。

保留一条主记录，并在 `duplicate_of` 中指向主样本；所有原始链接仍保留在来源表中。

## 6. 质量控制

- 每批抽查至少 20%，异常模板 100% 复核。
- 抓取与分析使用不同字段，避免分析结果回写污染原文。
- 所有结论标注样本量；5 篇试验结果不得外推为 138 篇总体规律。
- 没有互动数时，只能分析内容特征，不能建立阅读量因果模型。
- 对敏感、争议或可能不实内容，只记录文章表达，不将其自动视为已证实事实。

## 7. 首轮已知限制

桌面微信文章页未向本浏览器公开阅读、点赞、转发、收藏和评论数字。后续如需研究流量与内容的定量关系，必须另行获得可信互动数据，例如用户提供的榜单导出、后台数据或页面明确公开的数值。
